# 健康追蹤應用程式 💪

一個簡單易用的健康追蹤網頁應用程式，幫助你記錄體重、喝水量和飲食計劃。

## 功能特色

### 📊 體重記錄
- 記錄每日體重變化
- 查看體重歷史記錄
- 追蹤體重趨勢

### 💧 喝水追蹤
- 設定每日喝水目標
- 快速新增喝水量（250ml、500ml、1000ml）
- 視覺化進度條顯示完成度
- 查看每日詳細喝水記錄
- 追蹤歷史喝水習慣

### 🍽️ 飲食計劃
- 記錄每日三餐和點心
- 記錄食物內容和熱量
- 自動計算每日總熱量
- 按日期查看飲食記錄

## 如何使用

### 1. 開啟應用程式

直接在瀏覽器中開啟 `index.html` 檔案即可使用。

```bash
# 如果你有安裝 Python，可以快速啟動本地伺服器
python -m http.server 8000

# 或使用 Python 3
python3 -m http.server 8000

# 然後在瀏覽器中開啟
# http://localhost:8000
```

### 2. 體重記錄

1. 點選「體重記錄」標籤
2. 選擇日期
3. 輸入體重（公斤）
4. 點擊「新增記錄」按鈕
5. 在下方查看歷史記錄

### 3. 喝水追蹤

1. 點選「喝水追蹤」標籤
2. 可以使用快速按鈕（+250ml、+500ml、+1000ml）
3. 或輸入自訂水量後點擊「新增自訂水量」
4. 可以設定每日目標水量
5. 進度條會自動顯示完成度

### 4. 飲食計劃

1. 點選「飲食計劃」標籤
2. 選擇日期和餐別（早餐、午餐、晚餐、點心）
3. 輸入食物內容
4. 選填熱量（大卡）
5. 點擊「新增記錄」按鈕
6. 查看按日期分組的飲食記錄和總熱量

## 技術特點

- ✅ 純前端實現，無需後端伺服器
- ✅ 使用 localStorage 儲存資料
- ✅ 響應式設計，支援手機和平板
- ✅ 現代化的使用者介面
- ✅ 即時資料更新

## 資料儲存

所有資料都儲存在瀏覽器的 localStorage 中，資料不會上傳到任何伺服器。如果清除瀏覽器資料，記錄將會遺失，請定期匯出備份（未來功能）。
